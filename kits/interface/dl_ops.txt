# number  NAME           fields, in wire order                       says

# face (u8), u8, str (a NUL-terminated tail), strs (NUL-terminated
# strings, one at least, a tail), blob16 (a u16 length then that many
# bytes, a tail), bytes (the rest of the payload).

# and are never reused; gaps are deliberate.
